# Flight School 107 | Hybrid FAA Study Agent
This static website contains 97 original Part 107 questions, an original exam simulation, and a separately linked official FAA **sample-question** PDF.

## Live hosting
GitHub Pages needs to be enabled at Settings → Pages, with source: Deploy from a branch, branch: main, folder: / (root). The original career portfolio index.html remains unchanged. After Pages is enabled, open:
https://bionoma1234.github.io/bk-career/apps/flight-school-107/

## Offline
Open the site once on HTTPS to cache it, then install it from your browser if available. The Offline mode toggle blocks outgoing FAA / Engine Suite website links but does not disconnect your computer from Wi-Fi. The full app and exercises work without network; save the FAA PDF separately for offline reference.

FAA original sample PDF: https://www.faa.gov/sites/faa.gov/files/training_testing/testing/test_questions/uag_questions.pdf

## Privacy / Engine Suite
Local progress is stored on each device, not synced automatically to Engine Suite. Manual JSON Export / Import is available. Engine Suite private catalog: https://engine-suite.brian3-kim.chatgpt.site. Never include Engine Suite credentials in this public repository.
