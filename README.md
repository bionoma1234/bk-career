# Brian Kim — In Motion

Brian Kim's portfolio for video editing, videography and VFX compositing. The site uses a split portrait, lavender accents and charcoal backgrounds.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory. There are no build steps or dependencies; the page embeds its styles, scripts and imagery.

## Publish on GitHub Pages

In this repository's Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. GitHub then publishes this repository's homepage at its assigned Pages URL. Future pushes to main update the site.

The contact form prepares an email draft for the visitor to review and send. It does not send email automatically. Original video files were not present in the supplied archive, so project views retain descriptions and original links. Project imagery was recovered from the archive's contact sheets. The split portrait is a stylized edit of Brian's supplied photograph.
